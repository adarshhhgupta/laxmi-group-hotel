# 📖 About

Laxmi Group of Hotels is a modern luxury hospitality website developed to provide visitors with an immersive online experience. The project focuses on elegant design, responsive layouts, smooth navigation, and high-quality visuals to represent the brand across multiple destinations.

Built using **React** and **Vite**, the website delivers fast loading speeds, reusable components, and an optimized production build. Deployment is handled through **Cloudflare Pages** with automatic updates from GitHub.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/adarshhhgupta/laxmi-group-hotel.git
```

Navigate into the project

```bash
cd laxmi-group-hotel
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# 🏗 Production Build

Create a production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

---

# 🚀 Deployment Workflow

```text
Local Development
        │
        ▼
Git Commit
        │
        ▼
GitHub Repository
        │
        ▼
Cloudflare Pages
        │
        ▼
www.laxmigroupofhotel.com
```

Every push to the **main** branch automatically triggers a new production deployment through Cloudflare Pages.
